
# פורטל המחקר של ד"ר גיא וכטל

פורטל זה מציג את עבודתו המחקרית של ד"ר גיא וכטל מאוניברסיטת אריאל, כולל סימולציות אינטראקטיביות בחקר ביצועים, ניהול מערכות בריאות ותחבורה חכמה.

## איך להעלות את הפרויקט ל-GitHub?

אם יש לך טרמינל (Terminal) פתוח בתיקיית הפרויקט, הרץ את הפקודות הבאות:

1. **יצירת מאגר מקומי**:
   ```bash
   git init
   ```

2. **הוספת כל הקבצים**:
   ```bash
   git add .
   ```

3. **ביצוע Commit**:
   ```bash
   git commit -m "Initial commit: Research Portal with React & Simulators"
   ```

4. **חיבור ל-GitHub**:
   - כנס ל-GitHub וצור Repository חדש בשם `research-portal`.
   - העתק את הכתובת של המאגר (מסתיימת ב-`.git`).
   - הרץ את הפקודות הבאות (החלף את ה-URL בזה שהעתקת):
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/research-portal.git
   git push -u origin main
   ```

## חיבור ל-Vercel

1. כנס ל-[Vercel.com](https://vercel.com).
2. לחץ על **Add New** -> **Project**.
3. בחר את המאגר `research-portal` מרשימת ה-GitHub שלך.
4. לחץ על **Deploy**.

**זהו! האתר שלך יהיה באוויר תוך פחות מדקה.**
