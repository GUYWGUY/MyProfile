# פורטל המחקר של ד"ר גיא וכטל

אפליקציה זו בנויה בטכנולוגיית React + Vite ומעוצבת ברמה הגבוהה ביותר להצגת מחקר אקדמי וסימולציות מורכבות.

## הנחיות להעלאה לרשת (Deploy) - חינם לגמרי

הדרך הטובה ביותר להציג את האתר היא דרך פלטפורמת **Vercel** או **Netlify**.

### אפשרות א': Vercel (מומלץ)
1. הירשם ל-[Vercel.com](https://vercel.com) (חינם).
2. חבר את חשבון ה-GitHub שלך או השתמש ב-Vercel CLI.
3. הפלטפורמה תזהה אוטומטית שזהו פרויקט Vite ותבצע את הבנייה (`npm run build`).
4. תקבל דומיין אישי כמו `guy-wachtel.vercel.app`.

### אפשרות ב': Netlify (הכי מהירה)
1. הרץ במחשב שלך את הפקודה: `npm run build`.
2. תיווצר תיקייה חדשה בשם `dist`.
3. גרור את תיקיית `dist` לתוך ה-Dashboard של [Netlify](https://app.netlify.com/drop).
4. האתר באוויר תוך 5 שניות.

### אפשרות ג': GitHub Pages
1. העלה את הקוד למאגר (Repository) ב-GitHub.
2. בתוך `vite.config.ts`, וודא שה-`base` מוגדר לשם המאגר שלך.
3. תחת Settings > Pages, בחר ב-GitHub Actions כמקור הפריסה.
